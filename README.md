# Оазис

Сайт вымышленной базы отдыха и рыбалки «Оазис»: главная с планом территории и календарём клёва, услуги с прайс-листом, статистика улова и контакты с заявкой на звонок. Все цены, контакты и записи улова вымышлены.

## Стек

- Next.js 16 (App Router, Turbopack)
- React 19, TypeScript
- CSS Modules, шрифты Alegreya и Golos Text через `next/font`
- Графики на чистом HTML/CSS, без библиотек

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production-сборка
npm run start      # запуск собранного приложения
npm run lint
npm run typecheck
```

Нужен Node.js 20.9 или новее.

## API

| Метод | Путь | Что возвращает |
| --- | --- | --- |
| GET | `/api/lakes` | список водоёмов |
| GET | `/api/stats?lake=all\|begloe\|peschanoe\|polevaya` | сводка, разбивка по видам, наживкам и времени суток, прогноз и журнал улова; неизвестный водоём — `400` |
| POST | `/api/callback` | проверяет заявку `{ name, phone, comment? }`: ошибки — `422`, успех — сообщение для гостя |

Страница `/stats` рендерится на сервере с данными выбранного водоёма, а при переключении водоёма запрашивает `/api/stats`.

## Структура

```
src/
  app/            маршруты, route handlers, sitemap и robots
  components/     компоненты интерфейса и их стили
  lib/            данные (data.ts, site.ts), расчёт статистики, форматирование, валидация заявки
  assets/         фотографии
```

## Деплой на Vercel

Импортируйте репозиторий в Vercel: фреймворк определится автоматически, переменные окружения не нужны. Канонический адрес для `sitemap.xml` и метаданных берётся из системной переменной `VERCEL_PROJECT_PRODUCTION_URL`.

Старые адреса `/news` и `/statistic` перенаправляются на `/services` и `/stats`.
